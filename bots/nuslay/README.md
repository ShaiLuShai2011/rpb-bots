# 👑 NuSlay Bot

Телеграм-бот голосования для премии **NuSlay** — чата @HGDYFL.
Аналог премии SLAY: номинации, кандидаты, «свой вариант», этапы голосования, админ-панель.

## Возможности

**Для зрителей:**
- ✅ **Проверка участия в чате** — на каждое действие бот проверяет, состоит ли пользователь в Hooligan's Chat (@HGDYFL). Если нет — «⛔ Вы не являетесь участником чата» + кнопка вступления
- 🗳 **Голосование по очереди**: запустил бота → жмёшь «Голосовать» → номинации показываются одна за другой, после голосования автоматически открывается следующая (есть «▸ Пропустить»)
- 📄 **Пагинация**: если кандидатов больше 5 — листается стрелками ◀️ ▶️
- 🎖 **«Предложить свою кандидатуру»** — на этапе сбора предложений зритель выдвигает себя (имя или ник из профиля), заявка попадает на модерацию к админу
- ✍️ «Свой вариант» на этапе голосования — вписать любого кандидата, голос засчитывается сразу
- 📊 Результаты с процентами и прогресс-барами в реальном времени
- 🚫 Бан-лист (исключённые не могут голосовать)

**Для админов** (`/admin`):
- 🚀 **«Запустить голосование»** — голосование стартует только по этой кнопке (с опцией объявить старт в @HGDYFL). До этого у зрителей доступен только набор номинантов
- 🔒 **«Завершить голосование»** — фиксирует результаты
- 📋 CRUD номинаций: название, эмодзи, описание, скрыть/показать, удалить
- 🧑‍🤝‍🧑 Управление кандидатами: добавить, удалить, модерация заявок зрителей
- ⚙️ Три этапа: `Сбор предложений` → `Голосование` → `Завершено`
- 📊 Результаты со счётчиком голосов
- 📣 Рассылка всем пользователям бота
- 🏆 Генерация и публикация итогов в чат @HGDYFL (бот должен быть админом в чате)
- 🚫 Бан/разбан по ID
- 📄 `/export` — выгрузка всех голосов в CSV

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env
```

Заполни `.env`:

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | Токен от @BotFather |
| `ADMIN_IDS` | Telegram ID админов через запятую |
| `CHAT_ID` | Чат премии (по умолчанию `@HGDYFL`) — бот должен быть **админом чата**, иначе проверка участия работать не будет |
| `CHAT_TITLE` | Название чата для сообщений (по умолчанию `Hooligan's Chat`) |
| `EVENT_NAME` | Название премии (по умолчанию `NuSlay`) |

Свой ID можно узнать у @userinfobot.

## Запуск

```bash
python bot.py
```

Для постоянной работы — systemd, Docker или `nohup python bot.py &`.

## Сценарий проведения премии

1. **Подготовка** — админ создаёт номинации (`/admin` → Номинации). У зрителей кнопка голосования недоступна: только «🎖 Номинанты» и заявка себя
2. **📥 Набор номинантов** — зрители выдвигают себя кнопкой «🎖 Предложить свою кандидатуру»; заявки видны админу в разделе «Кандидаты» (✅ — одобрить). Админ может добавлять кандидатов и сам
3. **🚀 Старт** — админ жмёт «Запустить голосование» → зрители голосуют по очереди во всех номинациях. До нажатия голосовать нельзя
4. **🔒 Завершение** — кнопка «Завершить голосование», голоса фиксируются
5. **🏆 Итоги** — кнопка «Опубликовать итоги» отправляет список победителей в @HGDYFL
6. `/export` — выгрузить все голоса в CSV для проверки накруток

База — SQLite (`nuslay.db`), создаётся автоматически.

## Идеи развития

- Голос жюри с весом (например, 70% зрители / 30% жюри, как на SLAY)
- Ограничение голосования по вступлению в чат (проверка участника через `getChatMember`)
- Таймер автоматического завершения голосования
- Реакции-эмодзи на номинантов
